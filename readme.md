тестовое задание

стек: php 8.1, mysql, docker, nginx

инструменты: phpunit, phpstan, php-cs-fixer


### от себя

в задании сказано что оценивается простота но моя цель зацепить внимание ревьюера, поэтому вместо минимального варианта я постарался выдать что-то поинтереснее:

- Строгая типизация везде + phpstan
- Тесты — юнит-тесты на сущности
- паттерн репозиторий + отдельный слой Entity

конечно это не идеальная архитектура, есть куда развивать, с удовольствием обсужу на созвоне это

---

запустить проект:
```bash
cp .env.example .env
make setup
```

<http://localhost:8080>


команды:

- make up/make down поднять/остановить контейнеры

- make install установит зависимости композера

- make test запустит тесты

- make stan запустит phpstan

- make check линтер + пхпстан + тесты
